This is an application that I designed to create an ease of access for downloading the iMorph files. I found that it was sometimes a hassle to have to dig through files all the time to remove old iMorph clutter (older versions), replace them with newer versions and different versions as well (such as the menu and net versions if I felt like changing my version up). 


This application pulls all the archived retail files (TBC and other expansions will be added at a later date) from the mega.nz archive and downloads and automatically extracts the latest iMorph created for each type of iMorph (regular, menu or net types).

This application also starts iMorph for you without having to create any extra shortcuts for each new version that you might need to download (a feature where you can download each type of iMorph and select which one you want to start up might be implemented as well).

Anyways I feel free to comment on any issues, this is my first time creating a program intended for public as well!
